# Pawar Enterprises Letter Pad

Professional browser-based A4 letter pad generator for Pawar Enterprises.

## Features

- Premium Pawar Enterprises letterhead design
- Auto-generated reference / letter number
- Date, recipient, organization, address and subject fields
- Editable salutation, body, closing and signatory details
- Live A4 preview
- Browser draft auto-save using localStorage
- Print / Save as PDF support
- Responsive editor for desktop and mobile
- Company services and contact details embedded in the letterhead

## Usage

Open `index.html`, fill the letter details and use **Print / Save PDF**. In the browser print dialog select **Save as PDF** and keep the page size as A4.

## Notes

The current version is frontend-only and stores the active draft in the browser. It can be deployed as a static site on Render, Netlify, Vercel, GitHub Pages, or any standard static hosting provider.
